Wink Bite - Cookie Ordering System 🍪
A comprehensive, multi-role web application for managing a cookie bakery business with customer ordering, staff management, and administrative controls.

🌟 Features
Multi-Role System
Customer: Browse menu, add items to cart, place orders, track order status
Staff: View and update order status, manage order preparation
Admin: Full system control - user management, menu editing, order tracking, customer analytics

Core Functionality
Responsive Design: Works seamlessly on desktop, tablet, and mobile devices
Shopping Cart: Add/remove items, quantity management, real-time total calculation
Order Management: Complete order lifecycle from placement to delivery
Payment Integration: Multiple payment methods (GCash, Credit Card, Cash on Delivery)
Order Tracking: Real-time order status updates with visual progress indicators
User Authentication: Secure login/registration with role-based access
